# ✂️ Barber Shop Website  

A modern, responsive, and user-friendly **Barber Shop Website** built using **HTML, CSS, and JavaScript**. This project is designed to showcase a professional barber studio landing page with smooth navigation, service highlights, testimonials, contact UI, Google Map integration, and a clean footer layout — perfect for frontend portfolios and real business use.  

---

## 🌟 Features  

- Fully Responsive Design  
- Smooth Side Navigation Menu  
- Hero Section with CTA Buttons  
- Services Section with Hover Overlay Effects  
- Testimonials Layout  
- Contact Form UI  
- Google Map Embed  
- Social Media Icons  
- SEO Friendly Meta Tags  
- Newsletter Subscription UI  
- Modern Footer Design  

---

## 🛠️ Technologies Used  

- HTML5  
- CSS3  
- JavaScript  
- Font Awesome  
- Google Maps Embed
